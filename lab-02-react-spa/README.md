# React SPA — Temirlan Satybaldy

A one-page introduction built with React and Vite.

## What is on the page

- Name and photo (`myimage.JPG`)
- About Me
- Contact details with no phone number and no home address
- Four components: `Header`, `Hero`, `About`, and `Contact`

## Scripts

```bash
npm install
npm run dev
npm run build
```

The production base path is `/React/`, which matches GitHub Pages for this repository: https://magamariott.github.io/React/
